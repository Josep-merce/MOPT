Moltes dades amb un sol nom

Quan una variable normal no n'hi ha prou: guardar una llista d'elements del mateix tipus dins d'un únic vector.

🎯
Objectiu · criteris 2.2 i 2.5
Entendre què és un vector, com s'hi guarden i es llegeixen dades, i el patró per recórrer-lo amb un bucle. Veuràs que recórrer un vector és sempre la mateixa idea (criteri 2.2) i ho validaràs executant els programes a PSeInt (criteri 2.5).
1

Per què necessitem els vectors

El problema de tenir moltes variables

Imagina que vols guardar les 5 notes d'un alumne. Amb el que saps fins ara, necessitaries cinc variables: nota1, nota2, nota3, nota4, nota5. Funciona… però, i si fossin 100 notes? Seria impossible de gestionar.

Un vector resol això: és com una fila de caselles numerades, totes amb el mateix nom, on cada casella guarda un valor. Per dir de quina casella parlem, fem servir un número anomenat índex. Molt important: les caselles es comencen a comptar des del 0.

Un vector "notes" de 5 caselles. La casella 0 val 8, la casella 1 val 5, etc.
Definició senzilla
Un vector (o array) és un conjunt d'elements del mateix tipus guardats sota un sol nom. Cada element té un índex que diu la seva posició, començant pel 0.
2

Crear un vector i fer-lo servir

Declarar, guardar i llegir caselles

Crear un vector són dos passos: primer dius de quin tipus seran les dades (Definir), i després dius quantes caselles vols (Dimension). Per fer servir una casella concreta, poses el seu índex entre claudàtors: notes[0].

Sintaxi
Definir notes Como Entero;
Dimension notes[5];
Exemple · guardar i mostrar valors

      

        
Com funciona

        

          Dimension notes[5] reserva 5 caselles, numerades del 0 al 4. Amb
          notes[0] <- 8 guardem un 8 a la primera casella, igual que feies amb una variable normal,
          però indicant la posició. Escribir notes[0] ens torna el que hi ha dins: un 8.
        

      

    


    

      
⚠️ Compte amb l'últim índex

      

        Si un vector té 5 caselles, els índexs vàlids són 0, 1, 2, 3 i 4. La casella notes[5]
        no existeix i provoca un error. L'últim índex sempre és el nombre de caselles menys 1.
      

    

  


  
  

    

      3
      

        
Recórrer un vector

        
Visitar totes les caselles amb un bucle Para

      

    

    

      Guardar valors casella a casella va bé per a poques dades, però el potent dels vectors és poder
      recórrer-los: visitar totes les caselles, una per una, amb un bucle. Com que les caselles van del
      0 a l'últim índex, fem servir un Para on la variable del bucle fa d'índex.
    


    

      
Exemple · omplir el vector des del teclat i mostrar-lo

      

      

        
Com funciona

        

          La variable i val 0 a la primera volta, 1 a la segona… fins a 4. Com que escrivim
          notes[i], a cada volta treballem amb una casella diferent: notes[0],
          notes[1]… Per això el bucle ens deixa omplir les 5 caselles sense repetir codi. Posem
          i + 1 al missatge només perquè la persona vegi "nota 1, nota 2…" mentre que la casella, per dins,
          va del 0 al 4.
        

      

    


    

      
El patró que repetiràs sempre

      

        Recórrer un vector de N caselles és sempre el mateix: Para i <- 0 Hasta N-1 Hacer … notes[i] … FinPara.
        Canvia el que fas a dins (demanar, mostrar, sumar…), però l'estructura no canvia mai. Aquest és el reconeixement de patrons del criteri 2.2.
      

    

  


  
  

    

      4
      

        
Operacions habituals

        
Sumar, fer la mitjana i trobar el més gran

      

    

    

      Un cop saps recórrer un vector, pots combinar-ho amb el que vas aprendre a l'A1.3: un acumulador
      per sumar i la idea de màxim per trobar el valor més gran. Tot passa dins del bucle.
    


    

      
Exemple · mitjana i nota més alta de 5 notes

      

      

        
Com funciona, pas a pas

        

          suma comença a 0 i, a cada casella, hi afegim el seu valor (acumulador). Per trobar el
          màxim, suposem que la primera nota és la més alta i, cada cop que en trobem una de més gran,
          actualitzem maxim. En acabar el bucle, suma té el total i maxim la nota
          més alta. La mitjana és la suma dividida entre 5. Prova-ho amb notes 8 5 9 7 6: la suma és 35,
          la mitjana 7 i el màxim 9.
        

      

    


    

      
Per trobar el mínim

      

        És exactament igual que el màxim, però al revés: comences amb minim <- notes[0] i, dins del bucle,
        canvies minim cada cop que trobes una nota més petita (notes[i] < minim).
