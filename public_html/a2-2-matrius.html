Files i columnes

Quan una llista no n'hi ha prou: organitzar les dades en una graella de files i columnes amb una matriu.

🎯
Objectiu · criteris 2.2 i 2.5
Entendre què és una matriu (un array de dues dimensions), com s'hi accedeix amb dos índexs i el patró dels dos bucles niats per recórrer-la. És el mateix patró del vector, ampliat a files i columnes (criteri 2.2), i el validaràs executant-ho a PSeInt (criteri 2.5).
1

De la fila a la graella

Una matriu és una taula de files i columnes

A l'A2.1 vam veure el vector: una fila de caselles. Però moltes dades s'organitzen millor en una graella, com un full de càlcul o un tauler d'escacs. Per exemple, les notes de 3 alumnes en 4 assignatures: necessitem files (els alumnes) i columnes (les assignatures).

Una matriu (o taula) és exactament això: un array de dues dimensions. Per assenyalar una casella ja no n'hi ha prou amb un número: en calen dos, la fila i la columna. I, com als vectors, tots dos comencen a comptar des del 0.

taula[3,4] — 3 files × 4 columnes
col 0col 1col 2col 3
fila 07586
fila 14935
fila 26789
La casella marcada és taula[1,2]: fila 1, columna 2 → val 3.
Definició senzilla
Una matriu és una graella d'elements del mateix tipus. Cada casella s'identifica amb dos índexs: matriu[fila, columna], tots dos començant pel 0. El primer número sempre és la fila; el segon, la columna.
2

Crear i fer servir una matriu

Declarar amb dues mides i accedir amb dos índexs

Es crea igual que un vector, però el Dimension porta dos números: primer les files i després les columnes. Per fer servir una casella, indiques la fila i la columna entre claudàtors, separades per una coma.

Sintaxi
Definir taula Como Entero;
Dimension taula[3,4]; // 3 files, 4 columnes
Exemple · guardar i mostrar una casella

      

        
Com funciona

        

          Dimension taula[3,4] crea una graella de 3 files i 4 columnes (12 caselles en total). Amb
          taula[0,1] <- 10 guardem un 10 a la fila 0, columna 1. Recorda l'ordre: primer la fila,
          després la columna. Si els confons, escriuràs en una casella diferent de la que volies.
        

      

    


    

      
⚠️ Els índexs també tenen límit

      

        En una taula[3,4], les files vàlides són 0, 1, 2 i les columnes
        0, 1, 2, 3. Demanar taula[3,0] o taula[0,4] dóna error: igual que als
        vectors, l'últim índex és la mida menys 1.
      

    

  


  
  

    

      3
      

        
Recórrer una matriu

        
Dos bucles niats: un per a les files, un per a les columnes

      

    

    

      Per recórrer un vector fèiem servir un bucle. Per recórrer una matriu en necessitem dos,
      un dins de l'altre (niats). El bucle de fora tria la fila; el de dins
      passa per totes les columnes d'aquella fila. És com llegir una pàgina: baixes línia a línia (files) i, dins de cada
      línia, llegeixes paraula a paraula (columnes).
    


    

      
Exemple · omplir una matriu des del teclat

      

      

        
Com funciona

        

          El bucle de fora posa fila a 0 i, abans de passar a la fila 1, el bucle de dins recorre les
          columnes 0, 1 i 2. És a dir: per a cada fila es fan totes les columnes. L'ordre en què es visiten les caselles és:
        

        

          [0,0][0,1][0,2][1,0][1,1][1,2]
        

        

          Fixa't que taula[fila,columna] canvia de casella a cada volta del bucle interior. Aquest és el
          patró que faràs servir per a tota operació amb matrius.
        

      

    


    

      
El patró que repetiràs sempre

      

        Recórrer una matriu és sempre: Para fila … Hacer i, a dins,
        Para columna … Hacer, treballant amb taula[fila,columna]. Canvia el que fas a dins,
        però els dos bucles niats hi són sempre.
      

    

  


  
  

    

      4
      

        
Operar i mostrar com una graella

        
Sumar tots els elements i ensenyar la matriu bonica

      

    

    

      Amb els dos bucles niats i un acumulador (com el de l'A1.3) podem, per exemple, sumar tots els
      elements. I si volem mostrar la matriu en forma de graella, hi ha un petit truc per als salts de línia.
    


    

      
Exemple · omplir, sumar-ho tot i mostrar-ho en graella

      

      

        
Com funciona, pas a pas

        

          La suma comença a 0 i, recorrent totes les caselles amb els dos bucles, hi afegim cada valor.
          Per mostrar la graella, fem servir Escribir Sin Saltar dins del bucle de columnes
          (perquè els valors d'una fila surtin de costat) i, en acabar cada fila, un Escribir '' buit que
          fa el salt de línia per començar la fila següent.
